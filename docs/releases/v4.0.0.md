# 墨寒桌面助理 v4.0.0 發行說明／墨寒桌面助手 v4.0.0 发布说明／MoHan Desktop Assistant v4.0.0 Release Notes／墨寒デスクトップアシスタント v4.0.0 リリースノート

## 繁體中文

> 這是 v4.0.0 的正式 Release 說明。Windows 為正式支援平台；macOS 與 Linux 僅提供功能受限 Preview，不宣稱開發者實機認證或 Windows 功能同等。

### 專案週期與程式規模

- 墨寒專案從初始概念推進至 v4.0.0 發行里程碑的完整週期為 **2026/07/28 至 2026/08/16，共 20 天**；這是開發者實際完成的專案歷程，並非推估或虛構。GitHub 的公開發布仍須在本說明列出的發行閘門全部通過後執行。
- 此統計採目前 v4.0.0 候選工作樹的已追蹤 Python／Rust 原始碼，以實體行計算；不把文件、資產、CI YAML、建置產物或相依套件算作程式碼。
- 軟體本體有 **430 個模組、79,133 行**：425 個產品 Python 模組、77,977 行；5 個 Rust 原生加速模組、1,156 行。
- 品質與工程範圍另有 **362 個模組、82,084 行**：282 個測試 Python 模組、64,972 行；80 個稽核／封裝／建置與開發工具 Python 模組、17,112 行。合計 **792 個程式模組、161,217 行**。

### 主要內容

- 完成多感知、視覺隔離、主動互動、語音供應器回退與既有 2.5D 動畫路徑的整合；攝影機與雲端影像功能仍由使用者在控制台明確啟用，無法使用時不影響原有聊天、語音與角色功能。
- `app.py` 保持薄型 composition root；正式邏輯由明確分層模組承接，並以 Python 3.15、UTF-8、lazy import、JIT 預設路徑與完整回歸測試維護。
- Windows 正式包包含 Rust `1.97.1`、Maturin `1.14.1`、PyO3 `0.29.2`、Rayon `1.12.0` 建置的第一方 `_mohan_accel`；PCM16、嘴型音訊分析與 RGBA 合成在 Python／Rust 間逐項驗證。RGBA 僅在達到 `262,144` pixels 且有多個工作執行緒時條件式使用 Rayon。
- `PyBackedBytes` 借用原生輸入以避免額外輸入複製，但輸出仍建立新的 Python `bytes`；不宣稱端到端零複製，也不宣稱未實作的 SIMD。原生模組或單項運算失敗時，應用程式留下可觀測診斷並安全回退 Python。

### 重大版本功能總覽

- 這是重大功能版本，而非例行維護：多感知核心、安全空中互動、全身角色表現、主動陪伴與背景工作流程，在相容入口保留的前提下同步導入。
- 控制台已美化並重構為角色化旗艦控制中心；主題包、高對比、介面縮放、分區設定與四語導覽整合聊天、語音、視覺、衣裝、隱私與系統控制。主題包管理提供可驗證的安裝途徑，支援未來下載的炎劍官方包及使用者自行編譯包。
- 衣裝／主題包、場合處理與自主衣裝流程已擴充；所有手勢、裝置、攝影機、雲端視覺與系統能力都維持明確授權、確認、取消、冷卻與獨立安全回退。

### 多模態感知與隨包模型

- `MultimodalFusionHub` 接收既有手部 21 點結果、468／478 點 Face Mesh 結果、音訊片段與文字，輸出保守的表情、虹膜視線、語音活動、嘴型包絡及既有 2.5D 參數；478 點才提供虹膜視線，468 點安全回報未知。
- Windows 正式包將 `face_landmark_468.tflite`、`iris_landmark.tflite` 與 `silero_vad_v4.0.onnx` 隨 `assets/vision-models/` 提供，透過 OpenCV 5 DNN 在本機載入；模型來源、授權、大小與 SHA-256 見 `sbom/components.toml`、`THIRD_PARTY_NOTICES.md` 與 `docs/MULTIMODAL-MODEL-PROVENANCE.json`。
- `MultimodalController` 以單一有界背景工作槽執行融合，取消時以世代編號隔離過期結果；模型載入或推理不可用時，視線回報未知、語音活動回到低成本 RMS，既有聊天、語音與 2.5D 功能維持可用。
- 空中互動提供具防抖、遲滯與冷卻的捏合／空氣點擊、左右滑動與雙手擊掌觀察事件；事件不直接執行作業系統命令，辨識結果也不適用於安全、醫療或其他高風險決策。

### 發行邊界與未納入內容

- macOS／Linux 產物是功能受限 Preview；CI runner 的建置與 smoke 用於重現性證據，不等於開發者本人實機驗證。

This is the developer's actual completed project history, not an estimate or a fictional claim. Public GitHub publication remains contingent on clearing every release gate listed here.

### Highlights

- Integrates multisensory perception, privacy isolation, proactive interaction, speech-provider fallback, and the established 2.5D animation path; camera and cloud-image features remain explicitly enabled by the user in the control center and fail independently without breaking existing chat, voice, or character behavior.
- `app.py` remains a thin composition root; explicit layered modules own the product logic, maintained with Python 3.15, UTF-8, lazy imports, the default JIT path, and full regression tests.
- The formal Windows package contains the first-party `_mohan_accel` built with Rust `1.97.1`, Maturin `1.14.1`, PyO3 `0.29.2`, and Rayon `1.12.0`; PCM16, lip-sync audio analysis, and RGBA composition are checked item by item against Python／Rust paths. RGBA conditionally uses Rayon only at `262,144` pixels or more when multiple worker threads are available.
- `PyBackedBytes` borrows native inputs to avoid an additional input copy, while outputs still allocate new Python `bytes`; end-to-end zero-copy and unimplemented SIMD are not claimed. A native-module or individual-operation failure records observable diagnostics and safely falls back to Python.

### Major-version feature overview

- This is a major feature release, not routine maintenance: the multisensory core, safe air interaction, full-body character presentation, proactive companionship, and background workflows arrive together while preserving compatibility entry points.
- The control console has been visually redesigned as a character-centered flagship control center. Theme packs, high contrast, UI scaling, organized settings, and four-language navigation bring chat, voice, vision, wardrobe, privacy, and system controls together. Theme-pack management provides a validated installation path for future downloadable Flameblade official packs and user-compiled packs.
- Wardrobe/theme packs, occasion handling, and autonomous wardrobe flow are expanded. Every gesture, device, camera, cloud-vision, and system capability retains explicit authorization, confirmation, cancellation, cooldown, and independent safe fallback.

### Multimodal perception and bundled models

- `MultimodalFusionHub` accepts existing 21-point hand results, 468／478-point Face Mesh results, audio chunks, and text, then emits conservative expression, iris-gaze, voice-activity, mouth-envelope, and existing 2.5D parameters. Iris gaze is emitted only for 478 points; 468 points safely report unknown.
- The formal Windows package includes `face_landmark_468.tflite`, `iris_landmark.tflite`, and `silero_vad_v4.0.onnx` under `assets/vision-models/`, loaded locally through OpenCV 5 DNN. Model sources, licenses, sizes, and SHA-256 values are recorded in `sbom/components.toml`, `THIRD_PARTY_NOTICES.md`, and `docs/MULTIMODAL-MODEL-PROVENANCE.json`.
- `MultimodalController` runs fusion in one bounded background slot and isolates stale results with generation numbers. If model loading or inference is unavailable, gaze reports unknown and voice activity returns to the low-cost RMS path, while established chat, speech, and 2.5D behavior remains available.
- Air interaction provides debounced, hysteretic, cooled observations for pinch／air-click, left and right swipes, and two-hand high-five. Events do not execute operating-system commands directly, and recognition is not suitable for safety, medical, or other high-risk decisions.

### PySide6 Python 3.15 compatibility layer

- Publication still requires full regression, secret isolation, Windows packaging／installation, SBOM, SHA-256, artifact integrity, four-language documentation, and fallback verification.

### マルチモーダル知覚と同梱モデル

- `MultimodalFusionHub` は既存の手部 21 点、468／478 点 Face Mesh、音声断片、テキストを受け取り、保守的な表情、虹彩視線、音声活動、口形包絡、既存の 2.5D パラメーターを出力します。虹彩視線は 478 点の場合だけ出力し、468 点では安全に unknown とします。
- 正式 Windows パッケージには `face_landmark_468.tflite`、`iris_landmark.tflite`、`silero_vad_v4.0.onnx` を `assets/vision-models/` に同梱し、OpenCV 5 DNN でローカルに読み込みます。モデルの出典、ライセンス、サイズ、SHA-256 は `sbom/components.toml`、`THIRD_PARTY_NOTICES.md`、`docs/MULTIMODAL-MODEL-PROVENANCE.json` に記録します。
- `MultimodalController` は一つの有界バックグラウンドスロットで融合処理を実行し、世代番号で古い結果を分離します。モデルの読み込みまたは推論を利用できない場合、視線は unknown、音声活動は低コスト RMS 経路へ戻り、既存の会話、音声、2.5D 機能は利用できます。
- 空中インタラクションは、防振、ヒステリシス、クールダウンを備えた pinch／air-click、左右スワイプ、両手ハイタッチの観測イベントを提供します。イベントは OS コマンドを直接実行せず、安全、医療、その他の高リスク判断には使用しません。

### PySide6 Python 3.15 互換レイヤー

- 互換レイヤーは固定ダイジェストで検証した公式 PyPI wheel のバイナリ内容を使い、`6.11.1+mohan.py315.1` metadata を再構成します。`--ignore-requires-python` を使わず通常の pip resolver を使用し、Windows のクリーン環境で `pip check`、Qt import、offscreen smoke に合格しました。
- ローカルでコンパイルした PySide ソースを公式パッケージとして扱うものではありません。ローカル source-build は Windows の代替仕様として残します。上流 metadata の 3.15 宣言は Release の硬いゲートではありませんが、出所、ダイジェスト、導入証拠は監査可能でなければなりません。

### 公開範囲と除外

- macOS／Linux の成果物は機能限定 Preview です。CI runner の build と smoke は再現性の証拠であり、開発者本人の実機認証ではありません。
- PoseAtlas 完全版は、出典許諾、全24視角、正式 sidecar、真正な監査証拠がすべて揃った後に v4.0.0 とともに公開します。正式監査は fail-closed とし、候補画像や test fixture で代用せず、ひとつでも未達なら公開しません。
- プロジェクトに `openai` Python SDK の実行時依存はありません。OpenAI Responses API は Python 標準ライブラリ `urllib.request` から HTTPS で呼び出し、OpenAI は同梱コンポーネントではなく外部サービスとして扱います。
- 公開には完全回帰、秘密分離、Windows パッケージ／インストール、SBOM、SHA-256、artifact 整合性、四言語文書、フォールバック検証が必要です。
