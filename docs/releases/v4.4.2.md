# 墨寒桌面助理 v4.4.2 發行說明／墨寒桌面助手 v4.4.2 发布说明／MoHan Desktop Assistant v4.4.2 Release Notes／墨寒デスクトップアシスタント v4.4.2 リリースノート

## 繁體中文

> Windows 為正式支援平台；macOS 與 Linux 維持功能受限 Preview。本版集中修復 v4.3–v4.4 已公開能力的執行期接線、穩定性與可見回饋。

### 修正與完成接入

- 半身與全身說話統一維持參數化分層渲染，不再以舊角色原圖作為閉嘴回退；修正嘴型更新時的臉部破圖、黑色孔洞、重複下顎與半身／全身疊影。
- 一般 TTS 先驗證實際取樣率與聲道是否相容 WASAPI 裝置，不相容時安全使用系統既定輸出；並以播放世代隔離過期完成回呼，避免無聲、嘴型停止或下一句被前一句中止。
- 將 24 視角全身渲染快取限制在相鄰視角所需容量，避免載入 600 張圖層後長期保留約數 GiB 解碼影像而觸發「記憶體已滿」。
- 將左／右手狀態、身體能量與手勢節拍真正傳入全身渲染路徑；50 Hz 插值現在同時平滑嘴型、表情、視線、呼吸，手勢時會顯示安全的小幅袖擺與整體動勢。
- 放寬自然揮手辨識，不再要求拇指完全展開；修正首次揮手冷卻時間，並加入人在鏡頭前活動時的四語主動關懷，平衡／熱絡模式採不同節流間隔。
- 補齊夢囈、劍魂共鳴、感官共感與共同創作錄的正式執行期接線，使天氣、閒置、專案里程碑與情境狀態能產生可見或可聽回饋。
- 接入 GPT Image 2 雲端製衣供應器：以隔離區、透明圖層稽核與安裝前驗證產出半身、3/4 身及 24 視角全身素材；雨天可同時產生手持油紙傘。炎劍官方 DLC、使用者 DLC 與雲端生成服裝可並存並共同參與自主選裝。
- 保留使用者隨時手動換裝；預設鎖定 6 小時，控制台可設為 0–720 小時。數值欄 ▲／▼ 在上下限皆保持可用並循環變值。
- 修正組織搬遷後的權威 GitHub 儲存庫位址，並完成 Release Please 發布後自動觸發四平台封裝與資產上傳的流程。

### 維護交接

- OpenCV／ONNX 的 21 點手部模型負責辨識使用者動作；角色自身的手指不宣稱可由該模型任意生成。現有視覺回饋使用經稽核的姿態、視角、袖層與身體動勢，避免產生未授權或解剖錯誤的手部圖像。
- 雲端製衣只有在使用者開啟「允許墨寒雲端自創新衣」且安全金鑰可用時才會產生費用；失敗採 24 小時退避，已安裝服裝仍依情境自主選用。

### 修复与完成接入

- 半身和全身说话统一保持参数化分层渲染，不再用旧角色原图作为闭嘴回退；修复嘴型更新时的脸部破图、黑色孔洞、重复下颚及半身／全身叠影。
- 普通 TTS 会先验证实际采样率和声道是否兼容 WASAPI，不兼容时安全使用系统默认输出；播放世代隔离过期完成回调，避免无声、嘴型停止或下一句被前一句中止。
- 将 24 视角全身渲染缓存限制在相邻视角所需容量，避免 600 张图层长期保留数 GiB 解码图像并触发“内存已满”。
- 将左右手状态、身体能量和手势节拍真正传入全身渲染；50 Hz 插值同步平滑嘴型、表情、视线与呼吸，手势时显示安全的小幅袖摆和整体动势。
- 放宽自然挥手识别，不再要求拇指完全展开；修复首次挥手冷却，并加入四语视觉活动主动关怀。
- 补齐梦呓、剑魂共鸣、感官共感和共同创作录的正式运行时接线。
- 接入 GPT Image 2 云端制衣供应器，覆盖半身、3/4 身和 24 视角全身；雨天可同时生成手持油纸伞。官方 DLC、用户 DLC 与云端服装可并存并共同参与自主选装。
- 用户仍可随时手动换装；默认锁定 6 小时，可设 0–720 小时，▲／▼ 在上下限都保持可用并循环变值。
- 修正组织迁移后的权威 GitHub 仓库地址，并完成 Release Please 发布后的四平台自动封装与资产上传。

### 维护交接

- 21 点 OpenCV／ONNX 手部模型识别的是用户动作，不虚构为角色手指生成器；角色反馈使用已审计姿态、视角、袖层和身体动势。
- 只有用户启用云端自创且安全密钥可用时才会收费；失败后退避 24 小时。

## English

> Windows is the formally supported platform; macOS and Linux remain limited Previews. This release completes runtime wiring, stability, and visible feedback for capabilities introduced across v4.3–v4.4.

### Fixes and completed integration

- Keep both half- and full-body speech on the parametric layered renderers, with no legacy whole-character fallback when the mouth closes; fix torn faces, black feature holes, duplicated jaws, and half/full-body double images.
- Validate the real sample rate and channel layout before selecting WASAPI, safely falling back to the system default when incompatible; generation-check stale playback callbacks so one utterance cannot silence or stop the next mouth animation.
- Bound the 24-view full-body cache to adjacent-view working capacity, preventing the 600 decoded layers from retaining several GiB and triggering “memory full” warnings.
- Pass left/right hand state, body energy, and gesture beats into full-body rendering. The 50 Hz interpolation now preserves and smooths mouth, expression, gaze, and breathing, with conservative sleeve and whole-body motion for visible gestures.
- Recognize natural waves even when the thumb is partly tucked, fix the first-wave cooldown, and add throttled four-language proactive acknowledgements when visible activity is detected.
- Complete runtime wiring for somniloquy, sword-soul resonance, sensory synesthesia, and the shared chronicle.
- Add the GPT Image 2 cloud outfit provider with quarantine-first generation and transparent-layer auditing for half-body, three-quarter, and all 24 full-body views; rainy contexts may add a handheld oil-paper umbrella. Official DLC, user DLC, and cloud-generated packs coexist and share the autonomous candidate pool.
- Preserve manual outfit selection with a configurable 0–720 hour lock (default 6 hours). Both ▲ and ▼ controls remain enabled at boundaries and wrap correctly.
- Correct the authoritative GitHub organization repository and complete post–Release Please automatic four-platform packaging and asset upload.

### Maintenance handoff

- The OpenCV/ONNX 21-landmark model senses the user's hand; it is not represented as an arbitrary character-finger generator. Character feedback uses audited poses, views, sleeve layers, and conservative body motion.
- Cloud generation can incur charges only after the user enables it and a protected API key is available; failures use a 24-hour backoff.

## 日本語

> Windows は正式サポートプラットフォームです。macOS と Linux は機能限定 Preview を継続します。本版は v4.3–v4.4 で公開した機能の実行時接続、安定性、見える反応を完成させます。

### 修正と接続の完成

- 半身・全身の発話をパラメトリックレイヤードレンダラーに統一し、閉口時も旧全体画像へ戻しません。顔の崩れ、黒い穴、二重顎、半身／全身の二重表示を修正しました。
- 実際のサンプルレートとチャンネルが WASAPI に対応するか確認し、非対応時は安全にシステム既定出力へ戻します。再生世代で古い完了通知を隔離し、無音や口パク停止を防ぎます。
- 24 視点レンダーキャッシュを隣接視点分に制限し、600 レイヤーの数 GiB 常駐による「メモリ不足」を防ぎます。
- 左右の手状態、身体エネルギー、ジェスチャービートを全身描画へ接続しました。50 Hz 補間は口、表情、視線、呼吸を滑らかに保ち、安全な袖揺れと全身動勢で反応を見せます。
- 親指が少し隠れた自然な手振りも認識し、初回クールダウンを修正。カメラ上の活動に四言語で適度に話しかけます。
- 寝言、剣魂共鳴、感覚共感、共同年代記の実行時接続を完成しました。
- GPT Image 2 クラウド衣装プロバイダーを追加し、半身、3/4 身、24 視点全身を隔離生成・透明レイヤー監査します。雨天は手持ちの油紙傘も生成可能です。公式 DLC、ユーザー DLC、クラウド衣装は共存し、自主選装の候補になります。
- 手動着替えを常に保持し、既定 6 時間、0–720 時間に設定可能です。▲／▼ は上下限でも有効で循環します。
- GitHub 組織移行後の正規リポジトリを修正し、Release Please 公開後の四プラットフォーム自動パッケージ／資産アップロードを完成しました。

### 保守引き継ぎ

- OpenCV／ONNX の 21 点モデルはユーザーの手を認識するもので、キャラクターの指を任意生成するものではありません。キャラクター反応は監査済み姿勢、視点、袖レイヤー、控えめな身体動勢を使います。
- クラウド生成はユーザーが有効化し、保護された API キーが利用できる場合だけ課金されます。失敗時は 24 時間バックオフします。
