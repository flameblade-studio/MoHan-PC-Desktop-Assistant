# 墨寒桌面助理 v4.5.0 發行說明／墨寒桌面助手 v4.5.0 发布说明／MoHan Desktop Assistant v4.5.0 Release Notes／墨寒デスクトップアシスタント v4.5.0 リリースノート

## 繁體中文

> Windows 為正式支援平台；macOS 與 Linux 維持功能受限 Preview。本版完成 PoseAtlas 24 主視角／600 分層的正式驗收與黃金批次晉升，並大幅強化 50 Hz 說話效能與發行閘門。

### 重點變更

- PoseAtlas 24 主視角全數通過擁有者正式視覺驗收；yaw+000 權威升級為 2026-08-23 擁有者核准精修版，升級前完整備份並記錄 SHA-256。
- 600 分層晉升為獨佔所有權黃金批次：每個像素恰屬一個語意圖層，重組結果與權威圖零差；側面視角以臉部像素歸還修正 ornament 圖層溢出，封裝語意稽核 89 項欠帳全數清零。
- 嘴部權威由單視角擴至 13 個可見視角（yaw-090..+090），以黃金唇層 alpha 質心確定性校準；背面視角明確記錄為無嘴狀態。
- 離散眨眼契約完成：眨眼只在 20 ms 影格邊界切換完整權威狀態，不再產生半開半閉的合成混合影格；不對稱稽核同步改依此契約驗證。
- 半身取景時完全跳過全身合成，配合靜態底圖與遮罩區域快取，50 Hz 嘴型路徑 p95 由 27 ms 降至 6.6 ms。
- 發行閘門強化：靜態身份稽核導入擁有者驗收基線豁免制（以 SHA-256 鎖定驗收版檔案，任何位元組變更即恢復全規則稽核）；完整回歸 job 上限提高至 90 分鐘；測試依賴補齊 Pillow 光柵閘門。

### 維護交接

- 引用中繼資料（CITATION.cff）版本與發行日期已同步至 4.5.0；Zenodo 於 GitHub Release 發布時自動鑄造新 DOI。
- 第二代素體（換裝底盤）產線仍在開發中，未包含於本版；現行 600 分層即日後的「預設服裝包」，本版功能不受素體線影響。

## English

> Windows is the officially supported platform; macOS and Linux remain feature-limited Previews. This release completes the formal acceptance of the 24 PoseAtlas master views / 600 layers, promotes the golden batch, and substantially strengthens 50 Hz speech performance and the release gates.

### Highlights

- All 24 PoseAtlas master views passed the owner's formal visual acceptance; the yaw+000 authority was upgraded to the owner-approved 2026-08-23 master, with a full SHA-256-recorded backup taken before the swap.
- The 600 layers were promoted to an exclusive-ownership golden batch: every pixel belongs to exactly one semantic layer and the recomposition matches the authority image exactly; side views had face pixels reclaimed from the ornament layer, clearing all 89 packaging semantic-audit findings.
- Mouth authority expanded from one to 13 visible views (yaw-090..+090), deterministically calibrated from golden lip-layer alpha centroids; rear views are explicitly recorded as having no visible mouth.
- The discrete-blink contract is complete: blinking switches complete authority states only on 20 ms frame boundaries, never producing synthesized half-open blends; the asymmetry audit now verifies this contract instead of lerp smoothness.
- Half framing now skips the full-body composition entirely; combined with static-base and mask-region caching, the 50 Hz viseme path p95 dropped from 27 ms to 6.6 ms.
- Release gates hardened: the static identity audit gained an owner-accepted baseline waiver (files pinned by SHA-256; any byte change restores full-rule auditing); the full-regression job ceiling was raised to 90 minutes; Pillow was added for the raster gates.

### Maintenance notes

- Citation metadata (CITATION.cff) version and release date are synced to 4.5.0; Zenodo mints a new DOI automatically when the GitHub Release is published.
- The second-generation base-body (outfit-swap chassis) pipeline is still in development and not part of this release; the current 600 layers will become the "default outfit pack", and nothing in this release depends on the base-body line.

## 日本語

> Windows が正式サポートプラットフォームです。macOS と Linux は機能制限付き Preview のままです。本リリースでは PoseAtlas の 24 マスタービュー／600 レイヤーの正式検収とゴールデンバッチ昇格を完了し、50 Hz 発話性能とリリースゲートを大幅に強化しました。

### 主な変更

- PoseAtlas の 24 マスタービュー全てがオーナーの正式ビジュアル検収に合格。yaw+000 権威は 2026-08-23 のオーナー承認版へ更新し、更新前に SHA-256 記録付きの完全バックアップを取得。
- 600 レイヤーを排他的所有権のゴールデンバッチへ昇格：全ピクセルがちょうど 1 つの意味レイヤーに帰属し、再合成は権威画像と完全一致。側面ビューは顔ピクセルを ornament レイヤーから回収し、パッケージ語義監査の 89 件の指摘を全て解消。
- 口権威を 1 ビューから可視 13 ビュー（yaw-090..+090）へ拡張し、ゴールデン唇レイヤーのアルファ重心で決定論的に校正。背面ビューは口が見えない状態として明示的に記録。
- 離散瞬き契約が完成：瞬きは 20 ms フレーム境界でのみ完全な権威状態を切り替え、半開きの合成ブレンドを生成しません。非対称監査もこの契約に基づく検証へ変更。
- 半身フレーミング時に全身合成を完全にスキップ。静的ベースとマスク領域のキャッシュと合わせ、50 Hz 口形経路の p95 を 27 ms から 6.6 ms へ短縮。
- リリースゲート強化：静的アイデンティティ監査にオーナー承認済みベースライン免除を導入（SHA-256 でファイルを固定し、バイト変更で全ルール監査へ復帰）。完全回帰ジョブの上限を 90 分へ引き上げ、ラスターゲート用に Pillow を追加。

### メンテナンス引き継ぎ

- 引用メタデータ（CITATION.cff）のバージョンと公開日を 4.5.0 に同期。GitHub Release 公開時に Zenodo が新しい DOI を自動発行します。
- 第二世代素体（衣装換装ベース）パイプラインは開発中であり、本リリースには含まれません。現行の 600 レイヤーは将来「デフォルト衣装パック」となり、本リリースの機能は素体ラインに依存しません。
