## English

This candidate preserves the fully validated Windows EXE, MSI, and ZIP release
path and adds the first limited macOS Apple Silicon (arm64) and Intel (x86_64)
`.dmg` files (each containing a matching `.app`) plus a Linux x86_64
`.AppImage`. Each limited Preview is packaged on its native GitHub
runner and smoke-tested from the finished artifact, including all four UI
languages. These packages create an honest path for real-device testing; they
do not claim feature parity with the complete Windows application.

The macOS/Linux Preview enables only the launch surface, four-language status,
platform data paths, and explicit safety boundaries. Voice, the transparent
desktop character, the complete chat/productivity UI, cloud connectors, system
tools, autostart, and secret entry remain disabled. MoHan never falls back to
plaintext secret storage while native secure stores remain unverified.

Verification covers the Windows regression and installer suites, launching the
app from a mounted macOS DMG, executing the Linux AppImage, the four-language UI
contract, pinned dependencies, SHA256SUMS, separate Windows/Preview CycloneDX
SBOMs, packaged MIT and third-party notices, Gitleaks, CodeQL,
and Artifact Attestations. The maintainer has not yet manually validated these
previews on physical Mac/Linux computers; real-device reports are welcome.

## 日本語

この候補版は、検証済みの Windows EXE、MSI、ZIP 配布手順を維持しながら、
初めて機能限定の macOS Apple Silicon（arm64）版と Intel（x86_64）版
`.dmg`（各 `.app` 同梱）、および Linux x86_64 `.AppImage` を追加します。
それぞれの GitHub ネイティブ runner で作成し、完成した配布物
から起動と四言語画面を検査します。実機検証への入口を作るものであり、Windows
完全版との機能同等を主張するものではありません。

macOS／Linux Preview で有効なのは、起動画面、四言語の状態説明、OS ごとの
保存先、明示的な安全境界だけです。音声、透明デスクトップキャラクター、完全な
会話・作業画面、クラウド連携、システム操作、自動起動、秘密情報入力は無効です。
ネイティブの安全保存が確認されるまで、平文保存へ戻りません。

検証には Windows の全回帰・導入／削除、macOS DMG をマウントした後の app
起動、Linux AppImage の実行、四言語画面契約、固定依存関係、SHA256SUMS、
Windows／Preview 別の CycloneDX SBOM、配布物内の MIT ライセンスと第三者
ソフトウェア通知、Gitleaks、CodeQL、Artifact Attestation を含みます。作者は
まだ実機 Mac／Linux で手動確認していないため、実機報告を歓迎します。
