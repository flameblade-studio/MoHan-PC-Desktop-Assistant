# 墨寒桌面助理 v4.4.1 發行說明／墨寒桌面助手 v4.4.1 发布说明／MoHan Desktop Assistant v4.4.1 Release Notes／墨寒デスクトップアシスタント v4.4.1 リリースノート

## 繁體中文

> 這是 v4.4.1 的正式 Release 說明。Windows 為正式支援平台；macOS 與 Linux 僅提供功能受限 Preview。

### 修正

- 修復半身模式（HALF framing）說話／嘴型更新時出現的臉部破圖，將半身 idle 表情、眨眼、crossfade、姿勢切換、說話眨眼全部改用參數化分層渲染器（render_pose），並在閉嘴時回退 legacy sprite，避免正面 idle 回歸。
- 修復「長期記憶」分頁「編輯選取記憶」的「重要度」▲按鈕無法點選。
- 修復「聲音」分頁可編輯下拉選單黑色底色。
- 修復墨寒軟體無法發聲（普通 TTS 改用 WASAPI 預設輸出裝置）。

## 简体中文

> 这是 v4.4.1 的正式 Release 说明。Windows 是正式支持平台；macOS 与 Linux 仅提供功能受限 Preview。

### 修正

- 修复半身模式（HALF framing）说话／嘴型更新时出现的脸部破图，将半身 idle 表情、眨眼、crossfade、姿势切换、说话眨眼全部改用参数化分层渲染器（render_pose），并在闭嘴时回退 legacy sprite，避免正面 idle 回归。
- 修复「长期记忆」分页「编辑选中记忆」的「重要度」▲按钮无法点击。
- 修复「声音」分页可编辑下拉菜单黑色底色。
- 修复墨寒软件无法发声（普通 TTS 改用 WASAPI 默认输出装置）。

## English

> These are the formal v4.4.1 Release Notes. Windows is the formally supported platform; macOS and Linux are limited Previews.

### Fixes

- Fix the face tearing in half-body mode (HALF framing) during speech/mouth updates by switching half-body idle expressions, blinks, crossfades, pose transitions, and speaking blinks to the parametric layered renderer (render_pose), and fall back to the legacy sprite when the mouth closes to avoid front idle regression.
- Fix the unclickable importance ▲ button in the long-term memory editor.
- Fix the black background of the voice tab's editable dropdowns.
- Fix MoHan being unable to produce sound (regular TTS now selects the WASAPI default output device).

## 日本語

> これは v4.4.1 の正式な Release 説明です。Windows は正式サポートプラットフォームです。macOS と Linux は機能限定 Preview のみです。

### 修正

- 半身モード（HALF framing）の発話／口元更新時の顔の破綻を修正し、半身の idle 表情、瞬き、crossfade、姿勢切替、発話中の瞬きをすべてパラメトリックレイヤードレンダラー（render_pose）へ移行し、口を閉じるときは legacy sprite に戻して正面の idle 回帰を回避。
- 「長期記憶」タブの「重要度」▲ボタンが押せない問題を修正。
- 「音声」タブの編集可能なドロップダウンの黒背景を修正。
- 墨寒が音を出せない問題を修正（通常 TTS を WASAPI 既定出力デバイスに変更）。
