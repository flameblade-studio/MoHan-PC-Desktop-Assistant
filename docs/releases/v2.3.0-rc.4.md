# 墨寒桌面助理 v2.3.0 RC4／墨寒桌面助手 v2.3.0 RC4／MoHan Desktop Assistant v2.3.0 RC4／墨寒デスクトップアシスタント v2.3.0 RC4

## 繁體中文

- 導入參數化分層 2.5D 臉部系統：以不可變臉部姿態、連續嘴型參數、表情語意及可替換渲染介面，統一正面、左望與托腮三種姿勢的 50 Hz 嘴型與表情合成。既有圖片仍是權威美術來源，不引入影片，也不改變語音、設定或安全流程。
- 眨眼改為具世代保護的漸進透明度曲線，眼皮與雙頰紅暈在同一分層規則下合成；正面臉紅時閉眼不再被正常膚色突兀覆蓋，延遲事件也不能覆寫較新的表情狀態。
- 托腮微笑說話時保留眼角笑意，但嘴部暫時回到中性基底並只套用語音嘴型；說話結束後才恢復雙側上揚嘴角，避免笑嘴角與中央口形同時存在所造成的不自然殘影。
- 修正朝左且未托腮時的中性說話嘴型：所有嘴角與嘴唇邊界都由當前參數化影格共同合成，右側嘴角小黑線不再留在舊位置。
- 新增臉部資產尺寸驗證、動作控制器、渲染器契約、執行期接線與三項視覺回歸測試；實際執行路徑與視覺稽核工具共用同一套嘴型設定，避免測試與產品行為分歧。
- 聲音分頁中的朗讀引擎、Windows 聲線、OpenAI TTS 聲線與 Realtime 聲線現在皆於選取後立即儲存。OpenAI TTS 會在下一次朗讀使用新聲線；若 Realtime 對話正在連線，系統會安全重連並立即套用新聲線，不新增多餘的儲存按鈕。
- 完整自動化測試、四語文件、架構、治理、公開內容、安全、SBOM、跨平台預覽與封裝前檢查必須全數通過後才可發布。Windows x64 維持完整功能版；macOS arm64／x86_64 與 Linux x86_64 維持功能受限 Preview。

- 修复朝左且未托腮时的中性说话口型：所有嘴角与嘴唇边界都由当前参数化帧共同合成，右侧嘴角小黑线不再留在旧位置。
- 新增脸部资源尺寸验证、动作控制器、渲染器契约、运行时接线及三项视觉回归测试；实际运行路径与视觉审计工具共用同一套口型设置，避免测试与产品行为分歧。
- “声音”分页中的朗读引擎、Windows 声线、OpenAI TTS 声线与 Realtime 声线现在都会在选择后立即保存。OpenAI TTS 会在下一次朗读使用新声线；若 Realtime 对话正在连接，系统会安全重连并立即应用新声线，不新增多余的保存按钮。
- 完整自动化测试、四语文档、架构、治理、公开内容、安全、SBOM、跨平台预览及打包前检查必须全部通过后才可发布。Windows x64 保持完整功能版；macOS arm64／x86_64 与 Linux x86_64 保持功能受限 Preview。

## English

- Introduces a parametric layered 2.5D face system. Immutable face poses, continuous viseme parameters, expression semantics, and a replaceable renderer contract now unify 50 Hz mouth and expression composition across front-facing, left-facing, and chin-rest poses. Existing images remain the canonical artwork; no video is introduced, and voice, settings, and safety flows are unchanged.
- Blinking now uses a generation-safe progressive opacity curve, with eyelids and cheek blush composed under one layer policy. Closing the eyes while blushing no longer replaces the cheeks with an abrupt normal-skin patch, and delayed events cannot overwrite newer expression state.
- During happy chin-rest speech, smiling eyes remain while the mouth temporarily returns to a neutral base and applies only the active viseme. Both raised corners return after speech ends, preventing the unnatural overlap of smile corners and a changing central mouth.
- Fixes neutral speech while facing left without chin-rest. Every lip and mouth-corner boundary is composed from the current parametric frame, so the small dark line at the right mouth corner no longer remains at its previous position.
- Adds face-asset dimension validation, motion-controller tests, renderer contracts, runtime-wiring checks, and regression coverage for all three visual defects. The product runtime and visual-audit tool share one speech-frame configuration to prevent QA behavior from drifting away from production.
- The speech provider, Windows voice, OpenAI TTS voice, and Realtime voice now save immediately when selected. OpenAI TTS uses the new voice on the next utterance; an active Realtime conversation reconnects safely to apply its new voice immediately, without adding a redundant save button.
- Publication requires the complete automated suite, four-language documentation, architecture, governance, public-content, security, SBOM, cross-platform Preview, and packaging preflight gates to pass. Windows x64 remains the complete product; macOS arm64/x86_64 and Linux x86_64 remain limited Preview packages.
