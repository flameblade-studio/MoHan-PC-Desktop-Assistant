# MoHan Desktop Assistant v2.2.0 RC2

## 繁體中文

RC2 專注於一件會直接影響陪伴感的事情：墨寒說話時，聲音、嘴型與同一張臉
必須自然地一起開始、一起結束。托腮姿勢現在保留眼角笑意，但說話期間固定
左右嘴角，只讓中央嘴唇依 A／I／U／E／O 與開合程度變化，不再出現像咧嘴
大笑般的拉扯與殘影。

Realtime、Windows 本機語音、OpenAI 自然語音與 Azure Speech 現在共用
20 毫秒／50 Hz 嘴型節拍。音訊與第一個嘴型由同一播放閘門同步放行；播放
結束後，終止閘門會拒收遲到的母音，只允許最後的閉嘴訊號通過。這同時改善
開口慢半拍、母音切換黏滯、嘴巴先停，以及聲音結束後又突然張嘴等問題。

托腮待機的眨眼也改為完整覆蓋雙眼的共用遮罩。眼皮閉合時，不會再把睜眼
狀態的上眼線留在原位；一般待機與情境表情不再各自維護一套容易分歧的座標。

本版也強化 GitHub Draft Release 失敗後的安全復原與清理，並在四語 README
加入兩張 1600×900 創作歷程圖版。它們記錄炎劍如何逐格檢查眼睛、嘴角與
嘴型，因為真正的陪伴感往往取決於幾個像素是否仍讓她看起來像同一個人。

Windows x64 仍是完整功能版。macOS Apple Silicon、macOS Intel 與 Linux
x86_64 維持功能受限 Preview，尚未宣稱與 Windows 功能同等。所有既有使用者
資料、個人設定與自訂提示詞均會保留。

## 简体中文

RC2 专注于一件直接影响陪伴感的事情：墨寒说话时，声音、口型与同一张脸必须
自然地一起开始、一起结束。托腮姿势保留眼角笑意，但说话期间固定左右嘴角，
只让中央嘴唇按照 A／I／U／E／O 与开合程度变化，不再出现夸张咧嘴般的拉扯
和残影。

Realtime、Windows 本地语音、OpenAI 自然语音与 Azure Speech 现在共用
20 毫秒／50 Hz 口型节拍。音频与第一个口型由同一播放闸门同步放行；播放
结束后，终止闸门会拒收迟到元音，只允许最终闭嘴信号通过。这同时改善开口
慢半拍、元音切换黏滞、嘴巴先停，以及声音结束后再次张嘴等问题。

托腮待机眨眼也改为完整覆盖双眼的共用遮罩。眼皮闭合时，不会再把睁眼
状态的上眼线留在原位；普通待机与情境表情不再各自维护容易分歧的坐标。

本版也强化 GitHub Draft Release 失败后的安全恢复与清理，并在四语 README
加入两张 1600×900 创作历程图版，记录炎剑如何逐帧检查眼睛、嘴角与口型。

Windows x64 仍为完整功能版。macOS Apple Silicon、macOS Intel 与 Linux
x86_64 继续作为功能受限 Preview，尚不宣称与 Windows 功能相同。所有既有
用户数据、个人设置及自定义提示词都会保留。

## English

RC2 focuses on a detail that directly shapes companionship: MoHan's voice,
mouth, and identity must begin and end together. The chin-rest pose keeps its
smiling eyes, but both mouth corners now remain fixed during speech while only
the central lips follow A/I/U/E/O and jaw aperture. This removes the stretched
grin and corner ghosting that made the portrait feel unlike the same person.

Realtime, Windows local speech, OpenAI natural speech, and Azure Speech now
share one 20 ms / 50 Hz viseme clock. Audio and the first viseme leave the same
playback gate together. When playback ends, a finish gate rejects late vowels
and permits only the final closed-mouth cue. This addresses late openings,
sticky vowel changes, lips stopping before the voice, and a mouth reopening
after the sound has ended.

Chin-rest idle blinks now replace the complete bilateral eye area. Open-eye
eyeliner can no longer remain above closed eyelids, and idle and contextual
expressions no longer maintain separate mask coordinates that can drift apart.

This candidate also makes failed GitHub Draft Release publication safely
recoverable and adds two aligned 1600×900 creation-history panels to all four
README languages. They document Flameblade's frame-by-frame inspection of the
eyes, mouth corners, and lip sync—because a few pixels can decide whether she
still feels like the same companion.

Windows x64 remains the complete product surface. macOS Apple Silicon, macOS
Intel, and Linux x86_64 remain limited Preview packages and do not claim
Windows feature parity. Existing user data, personal settings, and custom
prompts are preserved.

## 日本語

RC2 は、寄り添う感覚に直結する一点を重視しました。墨寒の声、口形、同じ
人物としての顔が、自然に一緒に始まり、一緒に終わることです。頬杖姿勢では
目元の笑みを残しながら、発話中の左右の口角を固定し、中央の唇だけを
A／I／U／E／O と開口量に合わせて動かします。これにより、引き伸ばされた
笑顔や口角の残像を防ぎます。

Realtime、Windows ローカル音声、OpenAI 自然音声、Azure Speech は、共通の
20 ミリ秒／50 Hz 口形周期を使用します。音声と最初の口形は同じ再生ゲート
から開始され、再生終了後は遅延した母音を拒否し、最後の閉口信号だけを
通します。開口の遅れ、母音切り替えの重さ、口だけが先に止まる現象、音声
終了後に再び口が開く現象をまとめて防ぎます。

頬杖の待機中のまばたきでは、両目全体を覆う共通マスクを使用します。閉じた
まぶたの上に開眼時のアイラインが残らず、待機表情と状況表情が別々の座標を
持つことで生じていたずれも防ぎます。

GitHub Draft Release の失敗後も安全に復旧・清理できるようにし、四言語の
README には同じ 1600×900 制作過程図を2枚追加しました。目、口角、口形を
フレーム単位で確認する炎劍の姿勢を記録しています。

Windows x64 は引き続き完全機能版です。macOS Apple Silicon、macOS Intel、
Linux x86_64 は機能限定 Preview であり、Windows 版との同等性を主張しません。
既存の利用者データ、個人設定、カスタムプロンプトは保持されます。
