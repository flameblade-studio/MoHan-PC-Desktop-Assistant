## 简体中文

此目录是可重现的本地工作构建，不是正式 Release 资产目录。

PNG 文件是已规范化的原生 RGBA 素材。身体 sidecar 使用 alpha 轮廓定位；手部 sidecar 只记录项目 ONNX 手部模型依 `BUILD-METADATA.json` 固定增强流程产生的观测。自然遮挡一律通过明确声明表示，绝不虚构关键点坐标。

## English

This directory is a reproducible local working build. It is not a formal Release asset directory.

The PNG files are normalized native RGBA assets. Body sidecars use alpha-silhouette registration. Hand sidecars contain only observations produced by the project ONNX hand model after the fixed augmentations recorded in `BUILD-METADATA.json`. Natural occlusion is represented by explicit declarations and never by invented landmark coordinates.

Source authorization and redistribution remain blocked until the owner confirms the source rights and completes visual review.
