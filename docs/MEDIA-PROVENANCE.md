# 說明媒體世代來源清單／说明媒体世代来源清单／Documentation Media Generation Provenance／文書メディア世代プロヴェナンス

## 繁體中文

`docs/media/MEDIA-PROVENANCE.json` 是 `docs/media/` 全部圖片與影片的唯一清單；README 引用必須是其子集。每個項目記錄產生工具、產生時的 `POSE_ATLAS_GENERATION`、SHA-256 與 `auto_regenerable`；不可自動重產的檔案須保留明確的 `reason`，查不到直接證據時明記「來源待查」，不得推測填補。

`docs/media/mohan-demo.mp4` 已改為由 `tools/record_demo_video.py` 自動重產的二代影片。工具以 `Microsoft Yating` 的 `OneCore` 語音與 `ffmpeg` 離屏逐幀輸出，禁止改走 `SAPI`；影片長度跟隨正常語速音訊，超過 60 秒時應停下交由擁有者決定。

重跑方式：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
py -3.15 tools/record_demo_video.py
py -3.15 tests/test_readme_media.py
py -3.15 tests/test_release_automation.py
QT_QPA_PLATFORM=offscreen py -3.15 tests/run_all.py
```

重產後須以實檔更新 `SHA-256`，並確認 `docs/media/` 的實體圖片與影片集合和清單完全相同、README 引用均有登記；不得只手改世代或雜湊。

## English

`docs/media/MEDIA-PROVENANCE.json` is the single ledger for every image and video under `docs/media/`; README references must be a subset. Each entry records its generator, creation-time `POSE_ATLAS_GENERATION`, SHA-256, and `auto_regenerable`. A non-regenerable file requires an explicit `reason`; when no direct evidence exists, it is marked 來源待查 rather than filled by inference.

`docs/media/mohan-demo.mp4` is now a generation-2 video regenerated by `tools/record_demo_video.py`. The tool uses the local `Microsoft Yating` `OneCore` voice and `ffmpeg` for offscreen frame rendering, and must never use `SAPI`; normal-speed narration determines the video length, and a result over 60 seconds must be reported for owner review.

To regenerate:

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
py -3.15 tools/record_demo_video.py
py -3.15 tests/test_readme_media.py
py -3.15 tests/test_release_automation.py
QT_QPA_PLATFORM=offscreen py -3.15 tests/run_all.py
```

After regeneration, update `SHA-256` from the actual file, confirm that the physical image-and-video set under `docs/media/` exactly matches the ledger, and ensure every README reference is registered. Do not hand-edit only the generation or digest.
