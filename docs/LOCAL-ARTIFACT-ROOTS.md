# 本機美術證據根目錄／本地美术证据根目录／Local art evidence roots／本機美術証拠ルート

## 繁體中文

`scratchpad/` 與 `angle-expansion-luna-c/` 只存放本機美術製作、檢視與驗證證據，不是產品程式碼或發行內容。任何要進入產品的 Python 程式碼，都必須先移入 presentation、application、domain、integrations、infrastructure 五層中的明確責任邊界，並通過既有架構、來源安全、Python 3.15 與相關回歸閘門。美術素材則須依既有素材契約、擁有者外觀審閱與整合流程移入正式素材目錄。

## 简体中文

`scratchpad/` 与 `angle-expansion-luna-c/` 只存放本地美术制作、审阅和验证证据，不属于产品代码或发布内容。任何要进入产品的 Python 代码，都必须先移入 presentation、application、domain、integrations、infrastructure 五层中的明确责任边界，并通过现有架构、来源安全、Python 3.15 与相关回归门槛。美术素材则须依照现有素材契约、所有者外观审阅与集成流程移入正式素材目录。

## English

`scratchpad/` and `angle-expansion-luna-c/` contain local art production, review, and validation evidence only. They are outside product code and release payloads. Before any Python code enters the product, move it into an explicit owner within presentation, application, domain, integrations, or infrastructure and pass the existing architecture, source-safety, Python 3.15, and relevant regression gates. Art assets follow the existing asset contracts, owner appearance review, and integration process into formal asset directories.
