# MoHan Desktop Assistant v2.0.14 RC — First Public Preview

## 繁體中文

這是墨寒桌面語音互動虛擬助理的首次公開預覽版。

墨寒結合透明桌面角色、臺灣繁體中文文字與語音互動、AIUEO 嘴型、眨眼與
旗艦物理動畫、使用者管理的長期記憶、工作計時、待辦、提醒、權限控管工具、
可攜設定檔，以及可擴充的雲端與智慧家庭連接架構。

### 本版驗證

- 38／38 項自動測試通過。
- 25,000 次表情、姿勢、語音、注視與物理混合壓力測試通過。
- 公開內容防洩密稽核通過。
- Windows 封裝後自我檢查通過。

### 重要限制

Microsoft、GitHub 與 Home Assistant 的架構與安全邊界已建置，但尚未完成
真實帳號、儲存庫、主機及實體設備的端到端驗證，因此本版標示為 Pre-release。
請先使用非關鍵環境測試。

### 安裝

下載 `Windows-x64.zip` 與 SHA-256 檔，核對後完整解壓縮，再執行程式資料夾
內的 EXE。雲端 AI 需要使用者自己的 OpenAI API 金鑰與 API 額度。

## English

This is the first public preview of MoHan Desktop Assistant.

MoHan combines a transparent animated desktop character, Taiwan Traditional
Chinese text and voice interaction, AIUEO viseme lip synchronization, blink and
flagship physics animation, user-controlled long-term memory, work timers,
tasks, reminders, permission-gated tools, portable profiles, and extensible
cloud and smart-home connector architecture.

### Verification

- 38/38 automated test programs passed.
- A 25,000-step mixed expression, pose, speech, gaze, and physics stress test
  passed.
- The public-content secret audit passed.
- The packaged Windows application self-test passed.

### Important limitation

Microsoft, GitHub, and Home Assistant architecture and safety boundaries are
implemented but have not completed real-account, repository, server, and
physical-device end-to-end validation. This version is therefore marked as a
pre-release. Begin only with non-critical environments.

### Installation

Download the Windows x64 ZIP and SHA-256 file, verify the archive, extract it
completely, and run the EXE inside the application folder. Cloud AI requires a
user-owned OpenAI API key and API billing.
