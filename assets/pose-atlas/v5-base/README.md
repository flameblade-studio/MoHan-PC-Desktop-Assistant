# PoseAtlas v5-base 二代素體暫存素材／PoseAtlas v5-base 二代素体暂存素材／PoseAtlas v5-base second-generation base body, staged／PoseAtlas v5-base 第二世代素体の暫定素材

## 繁體中文

`assets/pose-atlas/v5-base/` 收錄二代素體（裸額高髻、無袖）的 24 個正規化 RGBA 視角與 landmarks／hands sidecar。每個視角以同角度的 `v4` 為身份參考、由託管生圖服務繪製，2026-09-02 經擁有者目視驗收為同一人。`BUILD-METADATA.json` 保留來源與正規化資料，`identity-audit-baseline.json` 是擁有者核准、以 SHA-256 釘住的靜態身份稽核豁免基準。`audit.json` 如實記錄手部稽核：素體裸臂裸腿，sidecar 宣告 skin_background，extra-digit 皮膚啟發式列為 skipped；21／24 通過，其餘 3 項（兩個右手指長比例、一個左拇指覆蓋）於 2026-09-02 由擁有者在手部接觸表上目視接受。2026-09-02 起執行期、封裝與 packaged self-test 皆載入本目錄（目錄名只在 `domain/constants.py` 的 `POSE_ATLAS_ROOT_NAME` 定義一次），`BUILD-METADATA.json` 的 `formal_promotion` 同日改為 `approved`（見 `promotion_note`）。正規化基準與 `v4` 不同：`target_sole_baseline` 1496（v4 為 1487）、`target_subject_height` 1406（v4 為 1404），約 9 px 的差異。`source_root` 所指的 `v5-source` 只存在於工作檔、未入庫，沒有任何閘門讀取它。`BODY_PROFILE_ID` 於後續獨立變更再升版。

## English

`assets/pose-atlas/v5-base/` holds the 24 normalized RGBA views and landmarks／hands sidecars of the second-generation base body (bare forehead, high bun, sleeveless). Each view was drawn by a hosted image service against the same-angle `v4` view as its identity reference and passed the owner's visual acceptance as the same person on 2026-09-02. `BUILD-METADATA.json` retains source and normalization data, and `identity-audit-baseline.json` is the owner-approved, SHA-256-pinned waiver baseline for the static identity audit. `audit.json` records the hand audit truthfully: the body has bare arms and legs, the sidecars declare skin_background, the extra-digit skin heuristic is listed as skipped; 21／24 pass, and the remaining 3 findings (two right-hand finger-proportion, one left-thumb coverage) were visually accepted by the owner on the hand contact sheet on 2026-09-02. Since 2026-09-02 the runtime, packaging, and the packaged self-test all load this directory (its name is defined once, as `POSE_ATLAS_ROOT_NAME` in `domain/constants.py`), and `formal_promotion` in `BUILD-METADATA.json` was re-stamped `approved` the same day (see `promotion_note`). The normalization baseline differs from `v4`: `target_sole_baseline` 1496 (v4: 1487) and `target_subject_height` 1406 (v4: 1404), a difference of about 9 px. The `source_root` value `v5-source` exists only as working files and is not in the repository; no gate reads it. `BODY_PROFILE_ID` is bumped in a separate follow-up change.
