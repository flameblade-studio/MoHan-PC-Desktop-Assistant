# 墨寒角色資料目錄／墨寒角色数据目录／MoHan Character Data Directory／墨寒キャラクターデータディレクトリ

## 繁體中文

此目錄是墨寒角色包資料的固定產品內路徑。角色身分、人格、台詞、聲音偏好與外觀契約依已核准的角色包格式放入子目錄，不改變執行期素材、使用者設定或畫面。封裝保留整個相對路徑，角色包另以 `mohan-pack-v1.0.3` 附於墨寒公開專案發布頁。角色素材與付費 DLC 均採 CC BY-NC-ND 4.0；DLC 與角色包的關係仍由擁有者決定。

## 简体中文

此目录是墨寒角色包数据的固定产品内路径。角色身份、人格、台词、声音偏好与外观契约按已批准的角色包格式放入子目录，不改变运行时素材、用户设置或画面。打包保留整个相对路径，角色包另以 `mohan-pack-v1.0.3` 附于墨寒公开项目发布页。角色素材与付费 DLC 均采用 CC BY-NC-ND 4.0；DLC 与角色包的关系仍由所有者决定。

## English

This is the stable in-product path for MoHan character-pack data. Approved subdirectories hold identity, persona, dialogue, voice preferences, and appearance contracts without changing runtime assets, user settings, or rendered output. Packaging preserves the complete relative path, and tag `mohan-pack-v1.0.3` supplies the separate pack on the public MoHan project release page. Character assets and paid DLC use CC BY-NC-ND 4.0; the DLC relationship to a character pack remains an owner decision.
